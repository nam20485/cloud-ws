Hetzner RAID 10 Automated Setup Guide

This guide will walk you through the process of automatically provisioning a Hetzner dedicated server and configuring a RAID 10 array using Terraform and Ansible.

Prerequisites

  • A Hetzner Cloud account.
  • A Hetzner API token with read and write permissions.
  • Terraform installed on your local machine.
  • Ansible installed on your local machine.
  • An SSH key pair. Your public key should be added to your Hetzner Cloud project.

Installing Ansible

If you don't have Ansible installed, here are the commands for common operating systems:

macOS (with Homebrew)

brew install ansible

Ubuntu / Debian

sudo apt update
sudo apt install software-properties-common
sudo add-apt-repository --yes --update ppa:ansible/ansible
sudo apt install ansible

Step 1: Provision the Server with Terraform

First, we'll use Terraform to create the server.

  1. Create a new directory for your project and navigate into it.
  2. Create a file named main.tf with the provided Terraform configuration. This file defines the server we want to create.
  3. Create a file named terraform.tfvars to store your API token. Add the following line, replacing YOUR_HETZNER_API_TOKEN with your actual token: 
    hcloud_token = "YOUR_HETZNER_API_TOKEN"
  4. Initialize Terraform: 
    terraform init
  5. Review the execution plan: 
    terraform plan
  6. Apply the configuration to provision the server: 
    terraform apply
    Terraform will output the server's IP address when it's done.

Step 2: Configure RAID 10 with Ansible

Now that the server is running, we'll use Ansible to configure the RAID 10 array.

  1. Create a file named inventory.ini and add the server's IP address to it.
  2. Create a file named playbook.yml with the provided Ansible playbook. This playbook contains the tasks to set up the RAID array.
  3. Run the Ansible playbook: 
    ansible-playbook -i inventory.ini playbook.yml

Step 3: Verify the RAID Array

Finally, let's SSH into the server and verify that the RAID 10 array is set up correctly.

  1. SSH into the server: 
    ssh root@<your_server_ip>
  2. Check the RAID status: 
    cat /proc/mdstat
    You should see your md0 device active and with 4 devices.
  3. Check the filesystem: 
    df -h
    You should see the /dev/md0 device mounted at /mnt/raid10.

Congratulations! You have successfully provisioned a Hetzner dedicated server with a RAID 10 array using Terraform and Ansible.
